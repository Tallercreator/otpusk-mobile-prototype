# График команды · мобайл

Интерактивный прототип мобильной версии раздела «График команды» (модуль «Отпуск») для юзабилити-тестирования.

- Сайт: https://tallercreator.github.io/otpusk-mobile-prototype/
- Версия по макету: `…/#mock`, с улучшениями: `…/#imp` (по умолчанию)
- Панель модератора со сценариями данных — долгий тап по логотипу «Отпуск».

Данные — фиктивные фикстуры («сегодня» прототипа — 5 августа 2026). Сборка: `build-pages.sh` в исходной папке оборачивает `index.html` артефакта в полный документ.
