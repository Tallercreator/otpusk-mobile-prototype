# Отпуск · График команды (мобайл)

Кликабельный прототип мобильного раздела «График команды» модуля «Отпуск» — открывается на весь экран, как приложение.

- Прототип: https://tallercreator.github.io/otpusk-mobile-prototype/ (версия по макету)
- Версия с предложенными улучшениями: https://tallercreator.github.io/otpusk-mobile-prototype/#imp
- Панель модератора (сценарии данных и переключение версии) — долгий тап по логотипу «Отпуск».
- На iPhone можно «Поделиться → На экран „Домой“» — откроется без адресной строки.

Данные — фиктивные фикстуры («сегодня» прототипа — 5 августа 2026).
